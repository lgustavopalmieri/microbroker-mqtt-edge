Use the **tlc-spec-driven** skill to **initialize the project**.

Run project initialization: ask the essential vision questions (what are we building, for whom/what problem, tech stack, v1 scope, constraints) a few at a time, then write `.specs/project/PROJECT.md`. Offer to create `ROADMAP.md` next.

If this is an existing codebase, suggest running `/spec:map` first so the project docs are grounded in what's already there.
